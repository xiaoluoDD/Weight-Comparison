# 称重对比软件

基于Qt6开发的称重对比软件，使用TCP客户端与称重设备进行通信。

## 项目结构

```
Weight Comparison/
├── WeightComparison.pro      # Qt项目文件
├── main.cpp                  # 程序入口
├── mainwindow.h/cpp          # 主窗口类
├── mainwindow.ui             # UI设计文件
├── tcpclient.h/cpp           # TCP客户端类
├── weightdata.h/cpp          # 称重数据模型类
└── README.md                 # 项目说明
```

## 功能模块

### 1. TCP客户端模块 (TcpClient)
- 连接/断开服务器
- 发送/接收数据
- 错误处理
- 连接状态管理

### 2. 主窗口模块 (MainWindow)
- TCP连接设置界面
- 称重数据表格显示
- 数据对比功能（待实现）
- 数据导出功能（待实现）
- 数据清空功能

### 3. 数据模型模块 (WeightData)
- 存储称重数据（时间戳、重量值、单位、状态）
- 数据比较操作
- 数据格式化输出

## 编译说明

1. 确保已安装Qt6开发环境
2. 使用Qt Creator打开 `WeightComparison.pro` 文件
3. 选择构建套件（Kit）
4. 点击构建按钮进行编译

或者使用命令行：

```bash
qmake WeightComparison.pro
make  # Windows下使用 nmake 或 mingw32-make
```

## 使用说明

1. 启动程序后，在"TCP连接设置"区域输入服务器地址和端口
2. 点击"连接"按钮连接到称重设备服务器
3. 连接成功后，程序会自动接收并显示称重数据
4. 使用"对比"功能对比不同时间的称重数据（待实现）
5. 使用"导出"功能将数据保存为文件（待实现）
