# PLC 模拟器 - 称重数据 TCP 服务端

用于模拟 PLC 设备，向称重对比软件发送 432 字节协议报文，便于联调测试。

## 使用方法

1. **启动 PLC 模拟器**：运行 `PlcSimulator.exe`（构建后位于 `../bin/` 目录）
2. **设置监听端口**：默认 8080，与称重软件默认连接端口一致
3. **点击「启动服务器」**：开始监听 TCP 连接
4. **在称重对比软件中**：系统设置 → 服务器地址 127.0.0.1，端口 8080 → 点击「连接」
5. **配置参数**：在「第一车参数」「第二车参数」标签页中设置生产模式、车型、装件完成、8 个工件的重量/条码/状态（0正常绿 / 1异常红）
6. **点击「发送指令」**：将 432 字节报文发送给已连接的称重软件

## 协议说明

- 一帧 432 字节 = 第一车 198 + 第二车 198 + **末尾 18 字（36 字节）**
- 单车：6 字节车头（生产模式、车型、装件完成）+ 8×(4 字节重量 + 20 字节条码)
- 末尾：2 个空字（4 字节预留）+ 16 个状态字（大端 Int16）
  - 状态字顺序：左车工件1~8，再右车工件1~8
  - 0=正常(绿)，1=异常(红)
- 与称重软件 `plcprotocol.h` 完全兼容
